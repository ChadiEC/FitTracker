![Image](https://github.com/user-attachments/assets/03ac8cb3-159c-4b37-b76a-6b546665a94b)

## Description du projet
Notre application vise à aider les personnes qui veulent s'initier au monde du fitness. Ils auront la possibilité de choisir un plan d'entraiment gratuit sur notre site selon leur besoin ou de choisir un coach qui sera mis à leur disposition pour un plan d'entrainement spécialisé, un suivi quotidien et des séances d'entrainement personalisés.

## About The Project

[![Product Name Screen Shot][product-screenshot]](https://example.com)

FitTracker est une application web dédiée aux sportifs amateurs et professionnels. Elle aide les utilisateurs à générer des plans d'entraînement et des régimes nutritionnels personnalisés. Vous pouvez choisir entre un plan gratuit ou bénéficier de l'expertise d'un coach personnel pour un suivi sur-mesure.

## Getting Started

These are the steps to get your local copy of the project up and running. Follow these steps to install and use the application locally.

### Prerequisites

Make sure you have the following software installed:

* **Java 17 or later**
* **MariaDB**
* **npm** (Node.js package manager)

If you don't have Java or MariaDB installed, follow these instructions:
- **Java 17 or later**: [Download Java](https://adoptopenjdk.net/)
- **MariaDB**: [Download MariaDB](https://mariadb.org/download/)
